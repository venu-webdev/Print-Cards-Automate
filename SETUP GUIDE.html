Shop PC setup guide

Card Print Studio · Epson L8050 PVC cards · Canon iR A4 Aadhaar sheets

Tip: press Ctrl + P to print this guide.

Steps

1What you need

Keep these ready before you start.

  • The shop PC (Windows 10 or 11) with internet
  • The zip file Print-Cards-Automate-shop.zip (from Google Drive)
  • Epson L8050 connected (USB or Wi-Fi), with ink, and its Disc/ID Card Tray
  • Canon iR office printer connected to the PC / network
  • A ruler in millimetres
  • 2–3 blank PVC cards for testing, a few A4 sheets
  • One real PVC card (e.g. an old ID card) to compare the size

2Copy and unzip the folder

  1. Download Print-Cards-Automate-shop.zip from your Google Drive to the shop PC.
  2. Right-click the zip → Properties → at the bottom tick Unblock → OK.
    Why: Windows marks downloaded files. Without this, the .bat files may be blocked with “Windows protected your PC”.
  3. Right-click the zip → Extract All… → choose a simple place, e.g. D:\CardPrint or C:\CardPrint → Extract.
  4. Open the extracted Print-Cards-Automate folder. You should see Setup.bat, Start Website.bat, Make Cards.bat, this guide, and the folders raw, export, plugins, templates, web.
Don’t run anything from inside the zip window – always from the extracted folder.

3Install Python 3.12

  1. Open python.org/downloads and download Python 3.12 (Windows installer, 64-bit).
  2. Run it. On the first screen tick Add python.exe to PATH ← very important.
  3. Click Install Now. When it says “Setup was successful”, click Close.
Check: press Win + R, type cmd, Enter, then type python --version. It should show Python 3.12.x. If it says “not recognized”, run the installer again → Modify/Repair and make sure “Add to PATH” is ticked.

4Run Setup.bat (one time)

  1. In the folder, double-click Setup.bat.
    If a blue “Windows protected your PC” box appears: click More info → Run anyway.
  2. A black window downloads the parts the tool needs (needs internet, takes 1–3 minutes).
  3. When it shows “Setup finished”, press any key to close it.
If it shows red errors: check the internet connection and run Setup.bat again. Take a photo of the message if it still fails.

5Start the website

  1. Double-click Start Website.bat. A black window opens and the browser opens http://127.0.0.1:5000.
  2. Keep the black window open while you work – closing it stops the tool. It also shows error messages if something fails.
  3. If Windows Firewall asks about Python, click Cancel (the tool only runs on this PC, it doesn’t need network access from others).
Shortcut: right-click Start Website.bat → Send to → Desktop (create shortcut) so staff can start it from the desktop every morning.

6Install the two printers in Windows

Epson L8050 Install the Epson L8050 driver from Epson’s support website (“Drivers and Utilities Combo Package”). Connect the printer. It should appear as EPSON L8050 Series.
Canon iR Install the Canon driver for your model (e.g. iR 5500 – “Generic Plus UFR II” or “PCL6”) and add the printer.
  1. Open Settings → Bluetooth & devices → Printers & scanners (Windows 11) or Settings → Devices → Printers & scanners (Windows 10).
  2. Click each printer → Printer properties → Print Test Page. Both must print a normal Windows test page before you continue.
Epson: for the Windows test page use plain A4 paper in the normal paper tray – not the card tray.

7Make test cards (no printing yet)

This checks the tool works on this PC. The raw folder already has test PDFs.

  1. In the website, leave the card type on Auto-detect.
  2. Drag these files from the raw folder onto “Drop PDFs or click to choose”:
    CardTest file
    Aadhaar PVCSUBR1992.pdf, KVEN1983.pdf (locked – opens by itself)
    PAN (with hologram)01011961.pdf
    Driving LicenceDAMODHARDL.pdf, DL-Type-1.pdf
    Voter IDVoter-ID.pdf
    Vehicle RCRC-SAMPLE.pdf
  3. Aadhaar A4 sheets: click the Aadhaar A4 tile, then drop SUBR1992.pdf.
  4. Ration card: click the Ration Card tile, type RC number 2821148232, then drop YALA1947.pdf (needs internet).
  5. Each file appears in the Exports list with a Front/Back preview. Click a preview to see it large.

8Epson L8050: card printer settings

Open Settings (top right) → Card printer · Epson.

SettingSet it to
PrinterEPSON L8050 Series – the badge should say Ready.
Card settingsAutomatic (Photo+ compatible) – uses the ID Card Tray and PVC card paper type, like Epson Photo+.
Quality & colour (Epson)Leave as it is for the first test. Later you can click Set up… / Change… to choose Epson quality (e.g. High) – Epson’s own window opens.
BorderlessOn (prints edge to edge, like Photo+ “Plastic ID card – borderless”).
Move right / Move down0 and 0 to start. You change these only after the alignment test.
Card width / height85.6 × 54 mm (standard PVC card).
Scale100 %
Rotation90° (portrait, like Photo+)

Click Save printer settings.

The detected line under Borderless should show the tray as the Disc/ID Card Tray and a PVC ID card paper type. If it says something is missing, switch to Custom and click Set up… → in Epson’s window choose Paper Source Disc/ID Card Tray and the PVC ID Card paper type → OK.

9Epson: alignment test on a blank card

  1. Still in Card printer · Epson, scroll to Alignment test → click Print alignment test.
  2. Wait until the printer’s disc light blinks. Put a clean blank PVC card in slot 1 of the Disc/ID Card Tray, printable side up, and insert the tray as the Epson manual shows.
  3. The printer pulls the tray in and prints a black outline, an orange inner frame, centre lines, mm ticks and a TOP EDGE arrow.
  4. Check the printed card:
    What you seeWhat to change
    Black outline sits on the card edges, all sides even✓ Perfect – nothing to change.
    Everything is shifted to the right by e.g. 1 mmMove right = -1
    Shifted to the left by 1 mmMove right = 1
    Shifted down by 1 mmMove down = -1
    Shifted up by 1 mmMove down = 1
    TOP EDGE arrow points to the bottom of the cardRotation = 270°
    Print is slightly too big / too small on all sidesScale e.g. 99.5 or 100.5
  5. Click Save printer settings and repeat the test on the other side of the same card (or a new card) until it’s right.
Use small steps (0.5 mm). Measure with the ruler how far the outline is from the card edge on each side.
Keep the tray clean. Borderless printing leaves a little ink on the tray – wipe it with a dry tissue now and then, or the next card gets marks on the back.

10Epson: print a real PVC card

  1. In Exports, find the card (e.g. the Aadhaar PVC from step 7) and click its Print button (printer icon, “Print on a PVC card”).
  2. Choose Front, then back, copies 1 → Print.
  3. When the disc light blinks, put a blank card in slot 1, printable side up, insert the tray. The front prints.
  4. Let the ink dry for a moment. Click Print back, turn the card over keeping the same top edge, put it back in slot 1, insert the tray when the light blinks.
  5. Check: photo brightness, colours, no white edge, back lines up with the front.
Card PDF button in the same window downloads an exact card-size PDF – useful if you ever want to print from Epson Photo+ instead.

11Canon iR: A4 settings and scale test

Open Settings → A4 printer · Office.

SettingSet it to
PrinterYour Canon iR printer
ColourOn (Aadhaar sheets are in colour)
Resolution600 dpi

These save automatically.

  1. Put plain A4 paper in the Canon. Click Print scale test page.
  2. Measure with the ruler:
    • The square must be exactly 100 × 100 mm.
    • The 150 mm ruler must measure 150 mm.
    • A real PVC card must fit exactly on the card outline (85.6 × 54 mm).
  3. Some corner marks may be missing at the paper edge – that is only the printer’s margin and is fine.
If the square is NOT 100 mm (e.g. 97 mm): open Windows Printers & scanners → Canon → Printing preferences. Set paper size A4, and turn off Fit to page / Scaling / Enlarge-Reduce / Manual scaling (or set it to 100%). Click OK and print the scale test again.

12Canon: print Aadhaar A4 sheets

  1. On the left, click the Aadhaar A4 tile, then drop the customer’s e-Aadhaar PDF.
  2. The result has three sheets: Full (whole page with the green tick + time), Both (front & back card cut-outs) and Small.
  3. Click the row’s Print button (“Print A4 sheets”). Tick the sheets you need, set copies, keep Colour on → Print.
  4. Cut along the lines and laminate. The card part should match a real card’s size (85.6 × 54 mm).
Done: once the scale test is right, every Aadhaar sheet prints at the correct size – the tool always prints at exactly 100%.

13If something goes wrong

ProblemFix
“Python is not installed” / “python is not recognized”Install Python 3.12 again with Add python.exe to PATH ticked (step 3).
Browser shows “This site can’t be reached”The black window is closed – double-click Start Website.bat again.
“The Windows print service (Print Spooler) is not running”Press Win + R, type services.msc, Enter → find Print Spooler → right-click → Start. Refresh the website.
“No printers found”Install the printer driver (step 6) and refresh the website.
Epson doesn’t take the tray / nothing printsInsert the tray only after the disc light blinks. Check the card is in slot 1, printable side up.
Card print is shifted or upside downRepeat the alignment test and adjust Move right / Move down / Rotation (step 9).
A4 sheet card is too smallTurn off “Fit to page” in the Canon printing preferences (step 11).
Ration card: “Could not reach the AePDS site”Check internet. The AePDS site is sometimes slow – try again in a minute.
“Empty file” / “Cannot open empty stream”The PDF is broken or 0 bytes – ask the customer to send it again.
Anything elseLook at the black window – the error text is there. Take a photo of it and of the screen.

14Daily use (short version)

  1. Double-click Start Website.bat (desktop shortcut).
  2. Pick the card type (or Auto-detect) → drop the customer’s PDF(s).
  3. Check the preview. Ration card: fix Telugu names / order in the row’s ⋯ menu → Update card.
  4. PVC card: Print → Front, then back → card in slot 1 when the light blinks → flip → Print back.
  5. Aadhaar A4: Print → choose sheets → Print on the Canon → cut & laminate.
  6. Close the black window at the end of the day.
Your printer settings are saved in plugins\epson_pvc\config.json and plugins\office_print\config.json. If you ever replace the folder with a newer version, copy these two files into the new folder.
